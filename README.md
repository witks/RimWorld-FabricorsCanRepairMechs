# RimWorld-FabricorsCanRepairMechs

RimWorld mod that allows Fabricors to repair mechs.

- Fabricors repair colony mechs that have auto-repair enabled.
- A Fabricor never repairs itself.
- A Fabricor never repairs a mech that is currently repairing something.
- A damaged Fabricor does not repair other Fabricors (no back-and-forth repairs).
- Only the vanilla Smithing "repair mech" job is affected, so any mech that can do Smithing, modded ones included, can do the repairs.

Requires Biotech and [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077).
